# ocr

PDF OCR（按需）：`inspector-ocr-runtime.ts` 分发识别引擎（PDFium + ONNX Runtime + PP-OCRv6 Small 模型，按平台按需下载验签，离线模式运行）；`ocr-component-manager.ts` 管理引擎状态（下载进度/取消，与设置页同构）；`pdf-ocr-toc-service.ts` / `pdf-page-ocr-service.ts` 识别（整范围/单页选择性 OCR，文本进启发式目录解析、几何进页缓存）；目录链路在解析前经 `@montree/ocr-core`（ocr-watermark）清洗跨页水印/页眉（几何发现+碎片亲和，表格行永不删除），再经 `@montree/ocr-core`（toc-geometry）用 spans 行框把右列页码钉回同行标题（串行配对看不见顺序打乱，几何优先、串行不抢）；`pdf-toc-detect-service.ts` 只做目录页范围探测（前部固定窗口min(40,总页数)、低清 1.5 档，评分见 `@montree/ocr-core`（toc-page-detect），只建议范围、不识别、不写缓存）；缓存 `userData/ocr-cache/`。页级缓存 `ocr-page-cache.ts`、目录缓存 `ocr-toc-cache.ts`。`pdf-page-geometry.ts` 只读页尺寸（pdfjs legacy getPage scale=1，不渲染不 OCR）：inspector 页对象不带宽高，导入写页缓存与单页识别归一化都靠它，拿不到尺寸就跳过不用假尺寸；交给 pdf.js 的是拷贝（`copyPdfBytesForPdfJs` 见 `@montree/ocr-core` 的 pdf-bytes），避免 transfer 掏空导入 Buffer。中英文字库内置于识别模型，无语言包。OCR 纯逻辑（目录抽取/重组/几何/页探测/评估、水印清洗、页词与原生质量判断，另含 pdf-bytes 与缓存 ports）见 `packages/ocr-core/`（`@montree/ocr-core`，原 `shared/reader/` OCR 部分；`shared/reader/` 现为空目录）；外部运行时版本 pin（PDFium/ORT/模型 revision + SHA）见同包 `inspector-pins`。
