# Agent 默认资源（只读，随安装包发布）

应用规则和 Skills 的只读初始化模板。首次启动以及后续连接时，仅补齐用户 `~/.montree/` 中缺失的文件；已有文件（包括空文件）不覆盖，用户自定义技能保留。运行时交给 SDK 的是用户目录，安装目录不作为运行资源入口。

文件名本身不赋予系统角色，也不会让任意 Agent 自动发现。

| 文件 | 说明 |
|------|------|
| `AGENTS.md` | 追加式宿主规则，由 SDK 对接运行时原生规则入口；当前与渲染端 `montree-static-skill.ts` 分别存储，锚点单测仅检测关键术语，不等于完整同源校验 |
| `skills/montree-render/SKILL.md` | 纯文档技能（渲染规范）；仅知识来源，不注册工具。agy 桥复制到会话临时附加目录原生发现；其他运行时按支持矩阵处理，MCP guide 保留兼容 |

约束（见 `.plan/acp-multi-runtime.md` 应用级规则一节）：

- 不向用户全局规则/技能目录或项目写入应用文件。
- 不把安装目录加入可写根；`userData/agent-profiles/<hash>/` 按需物化版本目录。
- 打包：`electron-builder.yml` `extraResources` 同步 `agent/` 目录；开发期按项目相对路径读取。
- 原生资格与精确版本由 SDK 支持矩阵决定；主会话和批注副会话均以自身送达结果裁决模式。已有磁盘 Codex 配置、未知版本、WSL、自定义供应商等未确认情形保持兼容。agy 0.1.24 支持会话级原生 Skills。

agy 使用 SDK 的资源准备接口，将用户 `~/.montree/` 交给桥；桥复制规则与 Skills 到会话临时附加目录，不把安装目录设为工作目录或写入用户全局配置。默认 MCP 同样会话隔离，正常关闭后清理。

本版不自动合并新版默认规则与用户修改；缺失文件会重新补齐。初始化失败时记录错误并按用户目录资源的实际可用情况降级，不偷偷改用安装目录。修改资源后重新连接 Agent 即可重新准备；会话临时副本的清理不会删除 `.montree`。开发版与安装版使用相同用户目录。
