# Desktop contracts

`acp-elicitation.ts` defines standard ACP form-elicitation IPC, request/reply types and shared schema/content validation. It supports single/multiple selections, text, numeric and boolean fields. Only form mode is advertised; URL mode remains unsupported. The bridge stays local until the published contracts package exposes it.

`translation.ts` defines the dedicated translation Agent IPC and preload bridge: connection/authentication, model configuration, sessions/prompts, and isolated status/stream events. The main process scopes these by trusted window and translation runtime, independently of the chat connection.

`agent-inspection.ts` defines window-scoped Agent resource inspection IPC: observed MCP health/tool schemas, locally discovered Skill metadata/full instructions, and revealing a discovered Skill file. It never transports MCP tokens or runtime credentials.

`html-preview.ts` defines the isolated local HTML preview: the `montree-html` scheme, register/update/release/resolve-link IPC, and the postMessage bridge messages between the preview page and the host (page messages are untrusted and only trigger restricted actions).

`acp.ts` defines the renderer-side synthetic ACP prompt-complete update used to release the current turn even when the prompt IPC response is discarded by a route/session generation guard. `terminal.ts` defines app-specific terminal IPC messages; `inline-completion.ts` defines the editor ghost-text completion IPC shared by main, preload and renderer (including document/heading/block hints); `inline-completion-provider.ts` defines the dedicated completion provider config IPC, auth mode, ChatGPT login status, model list and dynamic `/models` listing; `web-doc.ts` extends the published online-document fetch contract with an optional Markdown source and defines the bounded image-resource fallback IPC (`montreeWebDocImages`); `hn.ts` defines the real Hacker News feed contract (channel, story shape, cache metadata) and the `montreeHn` preload bridge; `feed.ts` defines the generic multi-source feed registry (Hacker News / Lobsters / RSS / arXiv / AI 前沿 / Linux.do), authenticated-source metadata and the `montreeFeed` / `montreeFeedAuth` bridges. Generic published contracts remain provided by `@yitom/contracts`; no local package substitution is used.
